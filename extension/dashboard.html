    Privacy — 100% local

    PromptLens has no server, no account and no telemetry. Detection, masking and this dashboard all run inside your browser. Every interception log lives only in this browser profile's local storage and is never transmitted anywhere.

    • Detection & masking happen on-device, at send time.
    • Logs are stored in chrome.storage.local — not in any cloud.
    • Removed at any time via Clear local history (History tab) or uninstalling.
